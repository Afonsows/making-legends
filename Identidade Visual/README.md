# 📜 Identidade Visual — Making Legends

Central de design e diretrizes oficiais do ecossistema **Making Legends**.

## 🚀 Como Visualizar o Guia Interativo:
Abra o arquivo [**`index.html`**](./index.html) diretamente em qualquer navegador web (Google Chrome, Edge, Safari, Firefox). Nele você encontra:
- A **Logo Oficial Homologada** em alta resolução
- Amostras de cores interativas com **cópia em 1 clique** de HEX e RGB
- Tipografia oficial demonstrada ('MAKING' e 'LEGENDS')
- Componentes do **Liquid Glass Design System**
- Diretrizes dos 5 Pilares de Hábitos e regras de interface
